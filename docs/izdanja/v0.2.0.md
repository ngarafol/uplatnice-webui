Uplatnice se mogu izvesti i uvesti, a ista slika radi i s Dockerom i s Podmanom.

## Dodano

- **Izvoz u JSON** i uvoz natrag (`Izvezi` / `Uvezi` na popisu uplatnica)
- **Uvoz datoteka iz uplatime.com** — format se prepoznaje automatski, pa stare
  datoteke prelaze bez prepisivanja
- `Dockerfile` umjesto `Containerfile`: `docker build .` i `podman build .` rade
  bez ikakvih zastavica

## Popravljeno

- IBAN se pri spremanju normalizira u velika slova (uvoz iz drugih alata često
  daje mala slova)

## Promijenjeno

- README prvo pokazuje povlačenje objavljene slike, gradnja iz izvora je alternativa
- `make` sam prepoznaje je li instaliran Docker ili Podman
